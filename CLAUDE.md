# CLAUDE.md — Hodu Pomodoro

Agent orientation for this repo. The user-facing intro lives in `README.md`;
this file focuses on what an agent needs to be productive quickly.

## What this is

A small, fully-native macOS SwiftUI app: a pomodoro timer with a pixel-art
beach scene and a tamagotchi cat named Hodu. No dependencies beyond the Swift
toolchain. Ships as a single `.app` bundle built by `build.sh`.

- Language: Swift 5 / SwiftUI + AppKit bridging
- Platform: macOS 13+
- Build system: SwiftPM (`Package.swift`) + a shell script that assembles the
  `.app` bundle from the release binary
- No tests, no CI, no external packages

## Build & run

```bash
./build.sh          # swift build -c release + assembles HoduPomodoro.app
open HoduPomodoro.app
```

For a faster dev loop you can `swift run` against the executable target, but
the status-bar item, floating panel, and Info.plist metadata only behave
correctly when launched as a bundled `.app`. When iterating on
`HoduApp.swift` / `AppDelegate`, rebuild via `build.sh`.

The app icon is generated by `Tools/make-icon.sh` (invokes
`Tools/GenerateIcon.swift`) and committed as `Resources/AppIcon.icns`.

## Architecture notes

- **Single source of truth**: `AppState` (`@MainActor`, `ObservableObject`) owns
  the timer, tasks, settings, history, and cat state. It's injected via
  `.environmentObject` into every view (main window, menu-bar popover,
  floating widget), so all three surfaces stay in sync automatically.
- **Three UI surfaces**, all backed by the same `AppState`:
  1. Main window (`ContentView`) — `WindowGroup` in `HoduApp`.
  2. Menu-bar popover (`MenuBarWidget`) — `NSStatusItem` + `NSPopover`,
     built in `AppDelegate.setupStatusItem()`. The status item title is
     kept live via a Combine sink on `state.objectWillChange`.
  3. Floating widget (`FloatingWidget`) — a borderless `NSPanel`
     (`.floating` level, `canJoinAllSpaces`, `fullScreenAuxiliary`).
     Auto-hides when the main window becomes key; re-appears when it
     resigns key (see `mainWindowBecameKey` / `mainWindowResignedKey`).
- **Timer**: `Foundation.Timer` at 1 Hz in `AppState.start()`. On `tick()`
  hitting zero, `finishSession()` plays the system "Glass" chime, increments
  pomodoro count on the active task, and auto-switches mode (long break every
  `cyclesUntilLongBreak` work sessions, else short break; break → work).
- **Persistence**: JSON files in
  `~/Library/Application Support/HoduPomodoro/`:
  - `tasks.json` — today's tasks
  - `settings.json` — durations + cycles
  - `history.json` — last 10 completed tasks (cap `AppState.historyLimit`)
  Written atomically on every mutation. No migrations — format changes
  require bumping the Codable shapes carefully or wiping the directory.
- **Day rollover**: on launch and on a scheduled timer firing at 00:00:05,
  `rolloverOldCompletedTasks()` moves any completed task whose
  `completedAt` is before `startOfDay(now)` into `completedHistory`
  (newest first, capped).
- **Cat**: `happiness` 0…1, nudged up by `petCat()`, decays every 20s via
  `decayTimer`. `blinkTimer` drives the blink animation at 3.5s. Mood
  emoji derived in `catMood`.
- **Pixel art**: every sprite in `PixelArt.swift` is `[String]` where each
  character indexes into a palette; `.` is transparent. `PixelSpriteView`
  uses SwiftUI `Canvas` to fill one `CGRect` per pixel, scaled to the
  container — so the art stays crisp at any window size and ships with
  zero image assets. To tweak Hodu, edit `Sprites.hodu`.

## Keyboard shortcut

`⇧⌘M` — minimize to floating widget. Registered as a `CommandGroup` in
`HoduApp.body`, dispatches to `AppDelegate.shared?.minimizeToWidget()`.

## Gotchas / things to know before editing

- **Main-thread only.** `AppState` is `@MainActor`. Everything that touches
  it (timers, async work) hops back via `Task { @MainActor in … }`. Keep
  that pattern; don't introduce background mutations.
- **`isAppMainWindow`** in `AppDelegate` distinguishes the main content
  window from the floating `NSPanel`. If you add another window/panel,
  make sure this predicate still does the right thing — the widget's
  auto-hide relies on it.
- **No LSUIElement.** This is a regular app with a Dock icon *and* a menu
  bar item. If the user wants menu-bar-only mode, that requires adding
  `LSUIElement` to `Info.plist` and rethinking `openMainWindow()`.
- **Status-item title** is updated via `state.objectWillChange` — that
  publisher fires *before* mutation, so the sink wraps the update in
  `DispatchQueue.main.async` to read post-change state. Don't simplify
  that away.
- **No tests.** Verify behavior by running the app. For UI/timer changes,
  actually run `./build.sh && open HoduPomodoro.app` and exercise the
  feature — type check alone is not sufficient.
- **Swift only; no Xcode project.** Everything builds from `Package.swift`
  via SwiftPM. There is no `.xcodeproj`.
